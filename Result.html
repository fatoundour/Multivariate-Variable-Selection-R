Protéome (FH) — Température × Stade d’imbibition

Adam Aabadli, Fatoumata Ndour, Myriam Abouda

Introduction

Contexte

  • Graines FH analysées en conditions Température × Imbibition
  • Données protéomiques hautement multivariées
  • Objectif : identifier les protéines sensibles aux conditions

Défi analytique

  • Données corrélées
  • Variabilité technique
  • Besoin d’un prétraitement rigoureux

Approche générale

  • Exploration & normalisation
  • Modèle linéaire multivarié
  • Sélection robuste (Lasso + stability selection)

Présentation du package MultiVarSel

  • estimate E : estime les résidus à partir du modéle linéaire multivarié.
  • whitening_test(E) : vérifie si les résidus sont déjà un bruit blanc.
  • whitening_choice(E, typeDeps) : choisit la meilleure structure de dépendance.
  • whitening(E, typeDep) : calcule \(\widehat{\Sigma}_q^{-1/2}\).
  • variable_selection(Y, X, square_root_inv_hat_Sigma) :
    applique Lasso + stability selection et renvoie les protéines sélectionnées.

Rappel du cadre mathématique : Modélisation des données

Nous utilisons le modèle linéaire multivarié :

\[ Y = X B + E, \]

où
- \(Y \in \mathbb{R}^{n \times q}\) contient les abondances protéiques,
- \(X\) encode la température et l’imbibition,
- \(B\) contient les effets recherchés,
- \(E\) regroupe les erreurs corrélées entre protéines.

Chaque individu vérifie :

\[ E_i \sim \mathcal{N}(0, \Sigma_q), \]

ce qui signifie que les protéines peuvent être fortement corrélées.

Lasso multivarié

Le Lasso estime :

\[ \hat{\beta}(\lambda) = \arg\min_\beta \left( \| y - X^\star \beta \|_2^2 + \lambda \|\beta\|_1 \right), \]

ce qui force plusieurs coefficients à 0
sélection des protéines réellement influencées par la température ou l’imbibition.

Pourquoi le blanchiment

Pour appliquer un Lasso fiable, on rend les protéines approximativement indépendantes :

\[ Y^\star = Y \, \widehat{\Sigma}_q^{-1/2}. \] Le but est d’avoir des colonnes de \(Y^\star\) plus comparables et quasi indépendantes.

Pourquoi la vectorisation

On vectorise ensuite les données :

\[ y = \operatorname{vec}(Y^\star), \qquad \beta = \operatorname{vec}(B), \]

et on définit :

\[ X^\star = (\widehat{\Sigma}_q^{-1/2})^\top \otimes X. \]

Ce qui donne un modèle linéaire classique :

\[ y = X^\star \beta + \varepsilon. \]

Stability selection

Le Lasso est répété plusieurs fois sur des sous-échantillons :
on retient les effets avec une fréquence de sélection élevée.

Structures de dépendance possibles

Le package MultiVarSel permet de tester plusieurs formes pour la covariance \(\Sigma_q\) :

  1. no_whitening
    Hypothèse : aucune corrélation (rarement vraie).

  2. AR(1)
    \[ \Sigma(i,j) = \rho^{|i-j|} \] Dépendance décroissante avec la distance.

  3. ARMA(p,q)
    Modèle plus flexible, utilisé dans les données ordonnées.

  4. nonparam
    Estimation libre de \(\Sigma_q\) à partir des résidus.

Le modèle choisi est celui qui donne les résidus les plus proches d’un bruit blanc.

MODÉLISATION LINÉAIRE MULTIVARIÉE (B̂ et Ê)

Nous ajustons un modèle linéaire multivarié utilisant uniquement l’interaction temperature:imbibition, ce qui permet de modéliser directement les 9 conditions expérimentales complètes.

Le modèle naïf : \[ Y = X B + E, \]

est estimé avec lm.fit, ce qui fournit :

  • B_hat : les effets estimés de chaque condition sur chaque protéine

  • E_hat : les résidus du modèle, utilisés pour la suite de l’analyse

Ces résidus sont indispensables pour :

  • tester la blancheur des erreurs,

  • choisir la structure de dépendance \(Σq\),

  • effectuer le blanchiment des données avant la sélection de variables.

Analyse du résulat

Tous les modèles testés (no_whitening, AR1, ARMA et nonparam) conduisent à une décision “WHITE NOISE”, avec des p-values élevées. Cela indique que les résidus du modèle linéaire ne présentent pas de dépendance marquée entre protéines. Le modèle “nonparam” affiche la p-value la plus élevée (0.996) et constitue donc le meilleur choix pour l’étape de whitening. Nous l’utiliserons pour calculer la matrice \(Σ_q^{-1/2}\) et obtenir les données blanchies Y*.

Code

# Nettoyage des noms des conditions
Freqs$Names_of_X <- Freqs$Names_of_X |>
  gsub("temperature", "", x = _) |>
  gsub("imbibition", "", x = _) |>
  gsub(":", "_", x = _) |>
  trimws()

# Indices sélectionnés
indices <- which(Freqs$frequency >= seuil)

# Construction des vecteurs Y* et X*
